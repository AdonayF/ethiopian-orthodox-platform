# Roadmap

## Phase 0 — Discovery
- [ ] Interview church stakeholders about current announcements/events workflows.
- [ ] Select the first church/community pilot and content owners.
- [ ] Agree on permission levels, bilingual scope, privacy and maintenance responsibilities.
- [ ] Sketch mobile-first page flows.

## Phase 1 — Technical foundations
- [ ] Scaffold Angular + TypeScript in `frontend/`.
- [ ] Scaffold FastAPI in `backend/` with a health check.
- [ ] Set up PostgreSQL and database migrations.
- [ ] Add Docker Compose for local development and example environment variables.
- [ ] Set up formatting, tests and CI.

## Phase 2 — MVP
- [ ] Public announcements list/details.
- [ ] Public events list/details.
- [ ] Authorized admin login and management UI.
- [ ] Server-side CRUD and permission checks.
- [ ] Mobile-friendly UI and basic English/Amharic localization.
- [ ] Accessibility and security review.

## Phase 3 — Pilot and future expansion
- [ ] Test with a small set of church volunteers.
- [ ] Get feedback and improve reliability and usability.
- [ ] Evaluate Orthodox calendar integration with reviewed source data.
- [ ] Explore approved resource library and source-linked search.

**Principle:** Ship a small useful product before expanding scope.
